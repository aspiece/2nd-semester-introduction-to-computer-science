## Check your understanding

Pick an answer for each question. You can try again until you get it right.

<div class="quiz" markdown="1">

<div class="q" data-answer="b" markdown="1">
**1. What is debugging?**

- Writing a program as fast as possible
- Finding and fixing errors in a program
- Deleting a program that has errors
- Adding comments to a program

<p class="why">Debugging means finding the cause of a problem in your code and fixing it.</p>
</div>

<div class="q" data-answer="a" markdown="1">
**2. Which line has a syntax error?**

- `print("hi"`
- `print("hi")`
- `name = "Sam"`
- `print(name)`

<p class="why">A syntax error breaks Python's grammar rules; <code>print("hi"</code> is missing its closing parenthesis.</p>
</div>

<div class="q" data-answer="c" markdown="1">
**3. Python shows an error message when you run your program. What is the best first step?**

- Ignore it and run the program again
- Delete the whole program
- Read the message, which usually names the type of error and the line number
- Restart the computer

<p class="why">Error messages tell you what went wrong and where, so reading them is the fastest way to a fix.</p>
</div>

</div>

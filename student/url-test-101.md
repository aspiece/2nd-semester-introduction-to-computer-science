{% raw %}## What you will learn

* Define and identify: **IDE**, **Python**
* Identify the key concepts that will be covered in the course
* Set up and log into an account for the course's online IDE
* Save and turn in a file via the online IDE

## Check your understanding

Pick an answer for each question. You can try again until you get it right.

<div class="quiz" markdown="1">

<div class="q" data-answer="c" markdown="1">
**1. What is an IDE?**

- A type of error message in Python
- A built-in Python data type
- A program where you write, run, and save code
- The name of the Python language itself

<p class="why">An IDE (integrated development environment) is the tool you use to write, run, and save your programs.</p>
</div>

<div class="q" data-answer="a" markdown="1">
**2. What is Python?**

- A programming language
- A website for turning in files
- A kind of IDE
- A type of account

<p class="why">Python is the programming language you will write code in; the IDE is just the tool you use to write it.</p>
</div>

<div class="q" data-answer="d" markdown="1">
**3. Why do you save a file in the online IDE?**

- So the computer can translate it into English
- So Python learns your name
- So the IDE can log out
- So your work is kept and can be turned in

<p class="why">Saving keeps your code in your account so you can come back to it and turn it in.</p>
</div>

</div>
